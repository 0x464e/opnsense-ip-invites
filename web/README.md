# Frontend

React, TypeScript/TSX, Vite, React Router, TanStack Query, and Tailwind CSS.

See the repository's [development guide](../docs/development.md) for local backend/proxy configuration and browser testing. `npm run dev` starts Vite on loopback port 5173; `npm run build` type-checks and produces `dist/`, which the production Go build embeds. `npm test` runs desktop and mobile browser workflows against a local mock-firewall fixture.
